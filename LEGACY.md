# Legacy releases

The `v1.4.0-rc1` and earlier releases on this repository are the old "hardening kit" for a prior
MCP checkout. They are kept only so existing users can still download exactly what they had before;
they are not maintained and are not the current guard.

Use the latest `v0.3.2` release assets and the source repository
https://github.com/Hawse1337/ansys-aedt-mcp for new deployments.
